# 🏛️ Prometheus: The Watcher in the Shell

Prometheus is your divine mentor—an autonomous loop that watches your terminal commands and offers concise, intelligent guidance. It’s the first step toward a truly proactive digital companion: always watching, never judging, guiding when it matters.

## Quickstart
```
brew install redis && redis-server
episodic serve --port 8000
pip install -r requirements.txt
cp .env.example .env
bash scripts/run_conductor.sh
```
Then, add to your shell:
```
source /path/to/producers/terminal_hook.zsh
export PROMETHEUS_ON=1
```
Run a few commands and feel Prometheus whisper wisdom from the heavens.
